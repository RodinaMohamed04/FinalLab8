# SkillForge Learning Management System 

# Overview

The project follows an Object-Oriented Programming (OOP) approach with a modular architecture that separates the application into Backend and Frontend layers.

The system allows:

- Administrators to manage the platform.
- Instructors to create and manage educational content.
- Students to enroll in courses, complete lessons, solve quizzes, and earn certificates.

All application data is stored using JSON files, making the project lightweight without requiring a database server.
